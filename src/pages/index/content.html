Start with a reproducible comparison

After installing the Python toolkit, run:

python -m codebase.cli benchmark goldbach --max-n 10000 --budget 64 --seeds 0 1 2 --output-dir results/my-comparison
python -m codebase.cli benchmark verify results/my-comparison

The first command writes the reference, candidate ledgers, hashes, and environment metadata. The second recounts every reference value with independent trial-division primality. Use a new output directory for each experiment.
