CollatzX

CollatzX builds and inspects finite Collatz trajectories. It records stopping times, peak values, parity ratios, and other features used by ProofX's directed search.

PX-COL-002 / frozen finite comparison

Does prefix screening pay for itself?

A 32-step policy was selected on development data, then frozen before testing three disjoint windows of 100,000 starting inputs. Every discarded prefix and selected continuation is charged. Seven methods share proposal pools and size quotas over 32 seeds.

At 1,024 selected trajectories. Each window contains 5,008 upper-tail targets; uniform expectation is 51.28192 hits.

Growth exceeds uniform expectation on charged-transition yield in all three windows. It does not dominate simpler methods: prefix odd count is better in every window, ascending selection is more efficient in two, and local timings establish no wall-time speedup. The complete archive retains all controls and quotas.

The independent checker recounted 300,000 fresh reference values and 903,168 selected records, including ranking, labels, quotas and work. This is an internally checked finite experiment, not external peer review or a proof of Collatz.

What It Computes

        

          

            
Trajectories

            
Builds finite sequences from a starting value and records convergence, stopping time, and peak value.

          

          

            
Features

            
Extracts parity, growth, entropy, and trend features used to rank candidates inside a run.

          

          

            
Ledgers

            
Writes candidate-level records through the shared FalsificationEngine for later inspection and replay.

          

        

        
A completed trajectory is evidence about that input only. It is not a proof of the Collatz conjecture.
